# What carried over from the 2026 robot

The baseline is the root MainPCB and LinePCB schematic and routed board in the team’s MainPCB2026 and LinePCB2026 folders. The reference commits are e96e161 and 520a0b5. The root line schematic and routed board agree on six ADCs and the local Teensy. The older LinePCB.csv also lists parts from another configuration. The differences below use the connected root designs.

| 2026 requirement and evidence | 2027 Revision C implementation | How to verify it |
|---|---|---|
| D1–D96 include 48 receivers and 48 illuminators. Six MCP3008s read Ch1 through Ch48. | 64 downward QRE1113GR emitter/receiver packages, eight MCP3008-I/SL converters, 64 separate pull-ups and two independently strobed halves. Fixed angular pitch is 5.625°. | On a green then white target, capture calibration. Inspect the full raw array and eight bank-health flags. |
| Line U7 is a Teensy 4.0. J2 sends its results to the main Teensy 4.1 over UART. | Same processor split. The local 4.0 scans, subtracts ambient light, calibrates and reports. Main Serial8 consumes checked packets and sends calibration requests and receives acknowledgments. | Unplug only the data link with motor power off, or use a prepared break-out cable. Observe stale status and loss of drive permission. |
| Main J9 and line J2 have six JST XH positions and both reference 5 V and 3.3 V. | Six-position XH main J16 to line J1. Populate 1, 2, 5, 6 straight through. Each Teensy supplies its own 3.3 V domain. | Continuity-test each wire and the two empty cavities before power. Use the Revision C harness. |
| Five VNH7070 stages drive four wheels and a ball-handling motor. | Four encoder-controlled 20D drives and one encoder-equipped 25D dribbler, using five external Pololu G2 stages. The external harness carries motor current. The main PCB handles direction, PWM, current feedback, shared fault and enable. | Jog each motor on a stand, match its encoder, and test the master disconnect, referee STOP, local STOP and driver fault. |
| Main J2 provides referee run, SW2 provides local start/stop, and JP1/JP2 select the robot. | Main J17 accepts the referee signal, J20 puts a physical RUN contact in series with it, J21 selects the role profile, and the hardware heartbeat gate controls all five drivers. | Either stop input must pull actual G2 SLP low. The role strap selects the slower 0.14 m/s translation setting. Open selects 0.24 m/s. Both are commissioning settings. |
| Main J11 is a 3.3 V break-beam input and U4 supplies heading. | J22 uses the same supply/signal/ground order and the selected Adafruit break beam. J15 accepts the Pololu MinIMU-9 v6. The firmware estimates gyro bias at rest and holds relative yaw during translation. | Block and clear the gate while observing USB status. Check IMU response, yaw sign and drift on the installed robot. |
| The CM5 carrier has camera CSI, USB host/device, Ethernet, HDMI, boot and fan support. | The OpenMV N6 performs vision internally. Main J14 carries the 3.3 V UART. Regulated VIN powers the camera and its own USB-C provides setup and image inspection. | Check the live image in OpenMV IDE, then distinguish a missing camera link, a fresh frame without a ball, and an orange candidate. |
| Main J1 provides a Bluetooth serial connection and STATE. J7 is labeled Arduino. J6 has LiDAR PWM and data. | Main J23 exposes UART7 plus STATE, line J6 exposes UART4 for auxiliary equipment, and line J5 exposes LiDAR data/PWM. The included pit diagnostics exercise serial traffic. Device-specific ranging, radio coordination and auxiliary application protocols require the selected peripherals. | Use a 3.3 V logic-level loopback or the specific module. The 5 V connector pin supplies power only. LiDAR PWM defaults low. |
| Line U8 carries 3.3 V, SPI, chip select and motion for an external optical-flow breakout. | Line J4 retains the eight-position ordering, shared SPI, independent CS and motion input. USB command p performs a register read. Wheel encoders provide the operating odometry input. | Confirm the selected breakout’s supply, logic level, register ID, optics and floor distance. Full optical-flow tracking needs the device driver and calibration. |
| The main schematic includes a connector for a separate kicker PCB and dedicated voltmeter/fan provisions. | The selected scoring mechanism is the dribbler. Battery telemetry moves to main J18 and USB. Any enclosure cooling uses the separately fused power harness. A powered kick is outside this revision’s feature set. | Check dribbler intake and release, temperature under sustained load, and battery telemetry against a meter. |
| Team mounting tabs, mechanical cutouts and connector access matter to the assembly. | Both boards use this season’s supplied outlines. A separate carrier bridges the different hole patterns. The CAD study includes the drive envelopes, board assemblies, controller envelopes and an allowance for the ring-link plug. | Check the full assembled robot with the actual brackets, battery, mirror, dribbler, wires and covers. |

The 2027 committee publication reviewed on November 24, 2026 is the November 21 draft. Soccer Vision uses a passive orange ball. The draft sets 180 mm diameter and height limits and a 15 mm capture depth. Its inspection guidance suggests 3 mm below the diameter limit. The four-wheel study measures 178.09 mm and leaves 1.91 mm across the diameter. Check the raised handle, accessible white marker, covered indicators and protected referee-module position on the complete assembly. White detection supplies an early boundary cue. The draft's out-of-bounds definition includes wall contact and movement fully into the penalty area.
